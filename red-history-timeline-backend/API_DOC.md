## 基础CRUD接口清单

### 事件管理
- `GET /api/events` - 获取事件列表
- `GET /api/events/{id}` - 获取单个事件
- `POST /api/events` - 创建新事件
- `PUT /api/events/{id}` - 更新事件
- `DELETE /api/events/{id}` - 删除事件

### 人物管理
- `GET /api/persons` - 获取人物列表
- `GET /api/persons/{id}` - 获取单个人物
- `POST /api/persons` - 创建新人物
- `PUT /api/persons/{id}` - 更新人物
- `DELETE /api/persons/{id}` - 删除人物

### 地点管理
- `GET /api/locations` - 获取地点列表
- `GET /api/locations/{id}` - 获取单个地点
- `POST /api/locations` - 创建新地点
- `PUT /api/locations/{id}` - 更新地点
- `DELETE /api/locations/{id}` - 删除地点

### 媒体管理
- `GET /api/media` - 获取媒体列表
- `GET /api/media/{id}` - 获取单个媒体
- `POST /api/media` - 创建新媒体
- `PUT /api/media/{id}` - 更新媒体
- `DELETE /api/media/{id}` - 删除媒体
